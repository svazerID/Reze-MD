# Plugin `tozapo` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tambah plugin `.tozapo` yang mengonversi snippet Baileys (CJS maupun ESM) ke zapo, menandai pola yang tidak bisa dipetakan dengan `// TODO(zapo):`.

**Architecture:** Satu file plugin `plugins/tozapo.js` mengikuti pola `plugins/toesm.js`: helper murni (tanpa I/O) untuk konversi, lalu `run()` yang mengambil `text`/reply, memakai `stripFence` + `stripLeadingCommand`, mengirim hasil lewat AIRich dengan fallback teks. Fungsi murni diekspos via `module.exports._test`.

**Tech Stack:** CommonJS, Node built-ins saja (tanpa dependency baru). `airich` dan `highlightJS` dari `plugins/toesm.js` (tidak diduplikasi).

**Spec:** `docs/superpowers/specs/2026-10-27-tozapo-baileys-converter-design.md`

## Global Constraints

- CommonJS (`require`/`module.exports`), bukan ESM.
- Tanpa dependency baru (tanpa parser AST).
- Komentar dan pesan user berbahasa Indonesia; pesan error diawali emoji (❌/⏳).
- Gaya project: tanpa semicolon di banyak tempat — ikuti `plugins/toesm.js`.
- Setiap perubahan fitur WAJIB menambah entri di `FIX_LOG.md` (entri baru di paling atas).
- Pesan commit polos, tanpa prefix `feat:`/`fix:` — kalimat biasa.
- Verifikasi minimal: `node --check <file>`. Tidak ada test framework di project ini.

## Review Focus

- Snippet Baileys yang memakai `sock.ev.on` dengan nama variabel berbeda (`conn`, `sock`, `wa`) — konversi nama event harus jalan apa pun nama variabelnya.
- Snippet yang sudah zapo dikirim ulang — tidak boleh dirusak (tidak ada yang berubah selain penanda kosong).
- Payload yang ikut tertempel prefix+command berulang (`.tozapo .tozapo const ...`) — harus dibersihkan sebelum konversi.
- Kode berisi string yang mirip API Baileys (mis. `'sock.sendMessage(...)'` di dalam string) — tidak boleh ikut diganti.
- Input kosong atau hanya prefix tanpa kode — harus dijawab dengan pesan ❌, bukan output kosong.

## File Structure

- Create: `plugins/tozapo.js` — seluruh logika konversi + plugin object.
- Modify: `FIX_LOG.md` — entri baru di paling atas.

Plugin memakai ulang dari `plugins/toesm.js`:

```js
const { stripFence, stripLeadingCommand, highlightJS } = require('./toesm')._test
```

`toesm.js` sudah mengekspor keduanya di `module.exports._test` (baris 129). Tidak perlu mengekspor ulang `airich`.

Test yang harus ada (assertion eksplisit):

```js
// t1: sendMessage text -> client.message.send
convertBaileysToZapo("await sock.sendMessage(jid, { text: 'halo' })").code
  // === "await client.message.send(jid, 'halo')"

// t2: sendMessage image -> payload type
convertBaileysToZapo("await sock.sendMessage(jid, { image: buf, caption: 'x' })").code
  // mengandung "client.message.send(jid, { type: 'image', media: buf, caption: 'x' })"

// t3: ev.on messages.upsert -> client.on('message')
convertBaileysToZapo("sock.ev.on('messages.upsert', async ({ messages }) => {})").code
  // mengandung "client.on('message'"

// t4: nama variabel lain
convertBaileysToZapo("await conn.sendMessage(jid, { text: 'a' })").code
  // === "await client.message.send(jid, 'a')"

// t5: makeWASocket
convertBaileysToZapo("const sock = makeWASocket({ auth })").code
  // mengandung "new WaClient("

// t6: pola tak dikenal -> TODO
convertBaileysToZapo("const md = await sock.groupMetadata(jid)").code
  // mengandung "TODO(zapo)"
// dan todos.length >= 1

// t7: kode sudah zapo tidak berubah
convertBaileysToZapo("await client.message.send(jid, 'a')")
  // { code: "await client.message.send(jid, 'a')", todos: [] }

// t8: API di dalam string tidak diganti
convertBaileysToZapo("console.log('sock.sendMessage(x)')").code
  // === "console.log('sock.sendMessage(x)')"

// t9: useMultiFileAuthState -> TODO, kode asli tetap ada
convertBaileysToZapo("const { state } = await useMultiFileAuthState('auth')").code
  // mengandung "TODO(zapo)" dan masih mengandung "useMultiFileAuthState"
```

### Task 2: Plugin object + command handler

**Files:**
- Modify: `plugins/tozapo.js` (tambah `run`, `module.exports`)

**Interfaces:**
- Consumes: `convertBaileysToZapo` dari Task 1; `stripFence`, `stripLeadingCommand`, `highlightJS` dari `plugins/toesm.js` `_test`; `airich` dari `lib/airich`.
- Produces: plugin object dengan `name: 'tozapo'`, `command: /^(tozapo)$/i`, `run(m, { conn, text, command })`.

- [ ] **Step 1: Tulis `run` + plugin object**

Perilaku yang dipatok:
- Input: `text?.trim()` atau `m.quoted ? extractText(m.quoted.message) : ''`
- Kosong → `m.reply('❌ Masukkan atau reply kode Baileys yang ingin diubah.')`
- Bersihkan dengan `stripFence(stripLeadingCommand(input))`
- Panggil `convertBaileysToZapo`, kirim via `airich.send` dengan judul `# 🔄 Baileys → zapo`, blok `airich.code(highlightJS(result.code), 'javascript')`, dan daftar TODO sebagai `airich.text` bila `todos.length`
- `catch` → fallback `m.reply` dengan fenced code (pola sama dengan `toesm.js` baris 113-116)
- Tambah `contextInfo: FORWARDED` seperti `toesm.js` baris 5-12
